# Opening Builder
Static site (no build step). Open `index.html` locally, or deploy:
1. Push this folder to a GitHub repo.
2. vercel.com → Add New Project → import the repo → Framework "Other" → Deploy.
3. Open the site, expand **Settings**, paste a Lichess API token (stored only in your browser).
Trees autosave to browser storage; use Save/Load for JSON backups (old notebook files load too).
